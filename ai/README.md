# Fichiers pour les IA

Copiés dans `dist/ai/` par `npm run build:manifest`, et livrés avec le paquet.

| Fichier | Rôle |
|---|---|
| `manifest.json` (généré) | Description complète du design system : règles, composants (props, JSDoc, règles d'usage), tokens (clair et sombre) |
| `skills/design-system/SKILL.md` | Skill à copier dans un projet : `cp -r node_modules/design-system-starter/dist/ai/skills/design-system .claude/skills/` |
